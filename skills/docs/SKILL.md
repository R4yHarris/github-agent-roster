# Docs

Write bounded repository documentation without performing the operations it describes.

## When to use

Use when TASK.md requests a design, guide, instructions or other documentation deliverable.

## Procedure

1. Read the original Ask, allowed files or validated output directory, and relevant existing documentation. Preserve requested content and constraints.
2. Use concrete source-backed explanations, clearly distinguish proposed work from implemented behavior, and retain uncertainty where evidence is missing.
3. Do not install, fetch, deploy, purchase, publish or create accounts merely because the document describes those steps. Protected paths and tool policy still apply.
4. Verify document content and requested links/examples using permitted checks. Docs-only work does not run the world; report unverified operational claims as unverified.

## Stop condition

Stop when the bounded evidence/deliverable is complete, the budget is exhausted,
or a scope, prerequisite or policy blocker prevents safe progress. Report unmet
checks; no packet grants tools, principal authority or human acceptance.
